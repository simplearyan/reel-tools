# About Reel
Reel is a family of small, free creative tools for making animation, video and sound. Each tool runs in your browser, lives in a single HTML file, and needs no install and no account.

## The story
Reel started as a pile of experiments. Over many months I built separate tools for animation, video editing and sound editing, each one testing a different idea, and they all ended up together in one old repository.

Now they are being rebranded, redesigned and reorganised as clean, production-ready tools under one name. Every tool is still independent, but they share one look, one structure and one home.

## What you can make
- Paper-cutout and card animations
- Videos with markup, motion and colour work
- Audio edits and sound experiments

## Why one file per tool?
Download a tool, open it, edit it, fork it. Nothing to install and nothing hidden, so every tool is easy to understand and easy to improve.

## Open source
Reel is open source. New tool ideas, bug fixes and polish are all welcome.
