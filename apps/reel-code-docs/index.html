01Quickstart

You need Node 18 or newer. Three steps get a scene on screen.

1

Create a project

terminal
npx reel init my-video
cd my-video
2

Write a scene

scene.ts
import { scene } from "reel"

scene("title", {
  text: "Summer cut",
  from: { y: -120, opacity: 0 },
  to:   { y: 0,    opacity: 1 },
  duration: 900,
  easing: "overshoot",
})
3

Preview it

terminal
npx reel dev

The timeline opens beside your code. Drag a keyframe and the numbers in scene.ts change.

02Core concepts

Reel Code has three ideas. Learn these and the rest of the API is just options.

Scene

One animated element, such as a title or a shape. Scenes stack as tracks on the timeline.

Keyframe

A value at a moment in time. Reel fills in everything between two keyframes for you.

Easing

The shape of the motion between keyframes: gentle, snappy or springy.

03Writing a scene

A scene describes where something starts, where it ends and how it travels. Pick a preset to see what each looks like, or set the values yourself.

Title

bounce

900 ms · overshoot

Title

slide

700 ms · ease-out

Title

spin

800 ms · ease-out

Title

fade

1200 ms · ease-in-out

scene.ts
import { scene, preset } from "reel"

// start from a preset, override what you need
scene("title", {
  ...preset("bounce"),
  text: "Summer cut",
  duration: 1200,
  underline: true,
})

Unset values fall back to x: 0, y: 0, scale: 1, rotate: 0, opacity: 1, so you only write what changes.

04Easing

Easing controls how speed changes over the duration. Choose one to see the curve and the motion.

05Timeline sync

The editor and your code describe the same scene. Edit either one and the other updates, so you never have to choose between drag-and-drop and a text file.

Edit the code

Change duration and the clip on the timeline stretches to match.

Drag the timeline

Move a keyframe and Reel rewrites the numbers in your file, keeping it tidy.

06Animate with AI

Describe the motion in plain words. Reel writes a scene you can read, edit and commit like any other code.

Prompt

“Spin the title in with a little zoom, then underline it.”

scene.ts · generated
scene("title", {
  from: { scale: 0.2, rotate: -180, opacity: 0 },
  to:   { scale: 1,   rotate: 0,    opacity: 1 },
  duration: 800,
  easing: "ease-out",
  underline: true,
})

Be specific

Name the element, the motion and the feel: “slide the title in from the left, slowly”.

Edit freely

The result is normal code. Change any value and the preview follows.

Iterate

Ask for changes like “make it snappier” and review the diff.

08Parameters

Turn any value into a variable, then render many versions of one scene from your own data.

scene.ts
import { scene, param } from "reel"

scene("title", {
  text: param("title", "Summer cut"),
  color: param("accent", "#FF8FB1"),
  duration: 900,
})
title"Summer cut"
accent#FF8FB1

Inputs

Name a value once and use it anywhere.

09Render & export

Render from the editor with one click, or from the command line for batches and automation.

terminal
# one video
npx reel render scene.ts --out scene.mp4

# one video per row of data
npx reel render scene.ts --data data.json --out out/

# vertical for Reels and Shorts
npx reel render scene.ts --size 1080x1920 --fps 30

Annotations never burn into an export unless you pass --marks.
